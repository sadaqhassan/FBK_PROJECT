# FBK — Faith & Dhikr Challenge Platform

FBK is a digital Islamic platform designed to encourage Muslims to maintain daily Dhikr and good deeds through challenges, points, rankings, and community motivation.

The goal of FBK is to make Dhikr more consistent, engaging, and motivating by combining Islamic practices with modern technology.

## ✨ Features

- 📿 Daily Dhikr and Tasbih tracking
- 🏆 Dhikr challenges and competitions
- ⭐ Points and rewards system
- 🥇 Leaderboard and rankings
- 👤 User profiles
- 📊 Personal progress dashboard
- 🔥 Daily activity and streak tracking
- 👥 Community motivation
- 🎯 Goals and challenges
- 🔐 Authentication and secure user accounts
- 📱 Responsive design for mobile, tablet, and desktop

## 🎯 Project Goal

Many people want to maintain regular Dhikr but struggle with consistency and motivation.

FBK aims to help solve this problem by providing:

- Daily reminders and goals
- Friendly competition
- Progress tracking
- Community motivation
- Achievement and ranking systems

The purpose is not to turn worship into a game, but to use technology as a tool to encourage consistency in good deeds.
